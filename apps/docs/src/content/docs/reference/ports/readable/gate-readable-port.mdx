---
title: GateReadablePort
---

## Interface

```ts
export interface GateReadablePort extends SnapshotPort {
  readonly gate: 0 | 1;
}
```

## PURPOSE

A port providing binary (ON/OFF) gate state.
Expresses binary event states such as whether a pointer's primary button is pressed.

| Property | Description |
| --- | --- |
| `gate` | `0` (inactive) or `1` (active) |

## NOTE

Must inherit from `SnapshotPort`.
When `snapshot()` is called, the port must capture the value at that moment and maintain it internally, ensuring that `gate` does not change until the next `snapshot()`.
