---
title: VectorReadablePort
---

## Interface

```ts
export interface VectorReadablePort extends SnapshotPort {
  vector(): Readonly<number[]>;
}
```

## PURPOSE

n 次元の数値配列を提供するポート。
`SimulationContext.target` として指定することで、`KineticsPort` が追従する目標ベクトルを定義する。

| メソッド | 説明 |
| --- | --- |
| `vector()` | スナップショット時点のベクトル値を返す |

## NOTE

`SnapshotPort` を継承しなければならない。
`snapshot()` が呼ばれたとき、その時点の配列を内部に確定して保持することを期待する。
同一 tick 内では `vector()` は常に同じ配列オブジェクト（`===` で等価）を返さなければならない。
配列の内容が変化しない場合は、`snapshot()` をまたいで同じ参照を返し続けてよい。
