## Common Conventions

All Readable Ports must inherit from [`SnapshotPort`](../snapshot-port).
When `snapshot()` is called, the port must capture the current value as internal state and continue returning that value until the next `snapshot()` is called.

Methods that return objects (`vector()`, `position()`, `size()`, etc.) must return the same object reference (equivalent by `===`) within a single tick.
If the array contents don't change, the same reference may be returned across multiple snapshots.
