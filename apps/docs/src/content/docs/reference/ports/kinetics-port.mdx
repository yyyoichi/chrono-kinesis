title: KineticsPort
---

## Interface

```ts
export interface KineticsPort extends ActivityPort {
  compute(dt: number, vector: Readonly<number[]>): void;
  readonly state: SimulationState;
}
```

## PURPOSE

多次元の運動演算を担うポート。
Simulator は毎固定ステップで `compute()` を呼び、目標ベクトルへ向けて状態を更新する。

| メンバー | 説明 |
| --- | --- |
| `compute(dt, vector)` | 目標ベクトルに向けて位置・速度を 1 ステップ分進める |
| `state` | 現在の `SimulationState`（絶対位置・相対移動量・速度・活動量）を返す |
| `isActive()` | 活動量が閾値を超えていれば `true` を返す（`ActivityPort` より） |

## NOTE

`ActivityPort` を継承する。
デフォルト実装は `Kinetics` クラス。内部では次元ごとに `EnginePort.compute()` を呼んで更新する。
`CloneableKineticsPort` を合わせて実装すると、同一設定の複製を生成できる。
