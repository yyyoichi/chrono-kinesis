title: EnginePort

## Interface

```ts
export type EngineResult = {
  position: number;
  velocity: number;
};

export interface EnginePort {
  compute(dt: number, position: number, velocity: number, target: number, out: EngineResult): void;
}
```

## PURPOSE

1 次元の物理演算アルゴリズムを実装するポート。
`KineticsPort` が次元ごとにこのポートを呼び出し、位置と速度を更新する。

| 引数 | 説明 |
| --- | --- |
| `dt` | ステップ時間（秒） |
| `position` | 現在位置 |
| `velocity` | 現在速度 |
| `target` | 目標位置 |
| `out` | 演算結果の書き込み先（`position`, `velocity`） |

## NOTE

標準実装として `SpringEngine`・`LinearEngine`・`DirectEngine` が提供されている。
カスタム実装を渡すことで任意の補間アルゴリズムを差し込める。
